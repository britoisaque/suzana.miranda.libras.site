Base de Dados de Alunos

Guarde os dados de contato e do curso de cada aluno. Essa lista também alimenta a aba de Presença e Reposição. Informe a data de início e o site calcula sozinho a previsão de término, com base na duração cadastrada no Painel de Módulos.

Importar alunos de uma planilha

Envie um arquivo Excel (.xlsx, .xls) ou CSV com os alunos já cadastrados em outro lugar. O site tenta reconhecer sozinho as colunas pelo nome do cabeçalho — funciona melhor se sua planilha tiver colunas como Nome, Email, Telefone, Curso (ou Módulo), Dia e horário e Data de início. A ordem das colunas não importa, só o nome de cada uma.
